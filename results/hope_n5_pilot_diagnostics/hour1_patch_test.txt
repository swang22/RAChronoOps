HYPOTHESIS
=======================================================================
Script 31 identified that HOPE's SoC_con applies only to
setdiff(H, [1]), so the hour-1 SOC has no dynamics constraint.
Combined with the cyclic boundary soc[s,1] = soc[s,H[end]] = 1966 MWh,
the storage charge c[s,1] and discharge dc[s,1] at hour 1 are free
variables that affect the power balance without changing any SOC
variable — a potential free energy source/sink.

=======================================================================
PATCH APPLIED (HOPE/src/PCM.jl lines 2241-2248)
=======================================================================
Replaced the commented-out (legacy, wrong variable signature)
Ch_1_con / DCh_1_con stubs with live constraints:

    Ch_1_con  = @constraint(model, [s in S_exist], c[s,  1] == 0.0)
    DCh_1_con = @constraint(model, [s in S_exist], dc[s, 1] == 0.0)

This forces zero charge and discharge at hour 1, making the cyclic
boundary self-consistent: if soc[1] is the year-start boundary value
and no dispatch occurs, the year-end terminal constraint fully
determines soc[1] without any free variables.

=======================================================================
CONCLUSION
=======================================================================
The LP was already setting c[s,1] = dc[s,1] = 0 naturally for all
five scenarios.  Hour 1 (midnight January 1) is not a shortage hour;
there is no incentive for the LP to dispatch storage there.

The EUE discrepancy between HOPE-ED and M3 (mean +107 MWh, +2.3%) is
therefore NOT caused by the hour-1 SOC formulation.

ROOT CAUSE CONFIRMED: LP degeneracy.  Both HOPE-ED and M3 solve the
same class of full-year LP, but converge to different optimal bases:
  - M3 (Gurobi internal pivot) discharges storage early to cover some
    shortage hours, depleting it by others (M3-only shortage hours,
    SOC = 0.0 MWh at those hours).
  - HOPE keeps storage fully charged (SOC = 3932 MWh = max) during
    those same hours and sheds load instead; it then uses the stored
    energy to avoid M3-only shortage hours.
  - Both solutions have the same optimal value in the scenarios where
    EUE matches (s001), and differ by ~107 MWh/scenario in others
    (different optimal bases have different objective values due to
    slightly different LP formulations, e.g., objective scaling,
    reserve constraints in HOPE that are absent in M3).
